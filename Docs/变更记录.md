## V1.1 — 2026/09/16

### 概述

对三层非易失存储栈进行重构：**用 RAM 块目录取代 `PrevOffset` 反向链扫描**来定位“某块最新记录”，新增**一次性批量读写（ReadAll / WriteAll）**快路径，精简 RAM 占用，调整块头格式，并将配置文件精简为通用示例。同时补齐接口头文件，使工程可编译。

一句话：**读更快（单块读 1 次数据读）、写更省（追加写 0 次旧数据读）、RAM 更小（队列不再内嵌数据缓冲、读写缓冲合并）**。

### 变更明细

#### 1. MiniFee（`Codes/Memory/MiniFee/MiniFee.c`，+619/−433）

数据结构：

| 项 | 变更前 | 变更后 |
| --- | --- | --- |
| 块头格式 | `BlockNumber(1) + Length(2) + PrevOffset(4) + CRC-8(1)` | `BlockNumber(3) + Length(4) + CRC-8(1)`（大端，去掉 PrevOffset） |
| 最新记录定位 | `lastRecordStart` 沿 `PrevOffset` 反向扫描 + 位图去重 | RAM 块目录 `dirOffset[MINIFEE_BLOCK_COUNT]` + `dirValid`（`0xFFFFFFFF`＝无记录） |
| 活动簇代次 | 每次回读簇头 | 目录构建时缓存 `activeClusterGen`，写簇头直接 +1 |
| 读写缓冲 | `blockDataBuf` / `writeBuf` 各自独立 | 合并为 `union jobBuf`（读/写作业互斥），省约 880B |
| 迁移去重 | `migrateBitmap[]` / `IsBitmapSet` / `SetBitmap` | 删除，改由块目录天然去重 |
| 通用扫描 | `HandleBlockScan` / `StartBlockScan` / `lastRecordStart` / `freeSpace` | 删除 |

状态机与流程：

- 主状态删除 `SCAN`、`READ_FIND_ADDR`、`WRITE_FIND_ADDR`、`WRITE_CHECK_CMP`；新增 `READ_BY_DIR`、`READALL_FILL`、`WRITEALL_APPEND`。
- 单块读：目录命中即 1 次数据读；目录无记录时返回**全零默认值并成功**。
- 单块写：不再做内容比对（去重上交 MiniNvm），追加写 0 次旧数据读。
- 迁移：目标簇 = `(活动簇 + 1) % 簇数`，仅**写前擦除目标簇**，按块目录逐块搬运最新记录（本次要写的块直接写新数据），写新簇头（Generation+1）后切换活动簇；源簇保留以便断电回退。
- 新增辅助函数 `MiniFee_ResetJob`（保留目录）、`MiniFee_ClearDirMap`、`ClusterHdrGen`、`MiniFee_NeededSpace`。

#### 2. MiniNvm（`Codes/Memory/MiniNvm/MiniNvm.c`，+401/−187）

- 队列条目精简为**仅存元数据**（`Operation` / `BlockId` / `TargetAddress`），删除每条目内嵌数据缓冲；读/写数据统一走上下文单一 `DataBuf`。
- `ReadAll`：清零全部 RAM buffer 后调用 `MiniFee_ReadAll` 逐块回调填充（无记录块保持全零）。
- `WriteAll`：仅落盘**脏块**（无脏块直接成功），调用 `MiniFee_WriteAll` 单遍选簇后连续追加。
- `WriteBlock`：与当前 RAM buffer 比对，一致直接返回 `E_OK`（不置脏、不入队）；不一致置脏入队，入队时快照源数据。
- 新增同步 RAM 接口 `MiniNvm_GetRamBuffer` / `MiniNvm_ReadRam` / `MiniNvm_WriteRam`（`WriteRam` 置脏）。
- 移除默认值恢复路径与 `MiniNvm_RestoreBlockDefaults` 实现，读取失败直接 `NOT_OK`。

#### 3. 配置精简为示例（`Codes/Config`）

- `MiniFee_Cfg.h/.c`：块表由 58 个产品专用块精简为 **3 个通用示例块**（`EXAMPLE_FLAG` 4B、`EXAMPLE_CONFIG` 10B、`EXAMPLE_VSS_DATA` 32B），`MINIFEE_MAX_BLOCK_DATA_SIZE` 调整为 32；簇表保留双簇示例（`0xFF200000/0x2000`、`0xFF202000/0x2000`），注释标明仅为示例。
- `MiniNvm_Cfg.h/.c`：块描述符结构由 6 字段（含 `RomBlockAddress` / `InitBlockCallback`）简化为 4 字段；`MININVM_QUEUE_SIZE` 改为用户自定义示例值 `8`（与块数解耦）；RAM buffer 精简为对应 3 个示例块。
- 两个配置头文件均注明“**示例配置**，集成时请按实际工程替换”。

#### 4. 接口头文件同步（使工程可编译）

- `MiniFee.h`：新增 `MiniFee_ReadAllCallbackType` / `MiniFee_WriteAllDataCallbackType` 类型与 `MiniFee_ReadAll` / `MiniFee_WriteAll` 原型；`MiniFee_BlockHeaderType` 更新为新布局（`uint32 BlockNumber` / `uint32 Length` / `uint8 CheckSum`，去掉 `PrevOffset`）。
- `MiniNvm.h`：新增 `MiniNvm_GetRamBuffer` / `MiniNvm_ReadRam` / `MiniNvm_WriteRam` 声明；移除无实现的 `MiniNvm_RestoreBlockDefaults` 声明与 `MININVM_REQ_RESTORED_FROM_ROM` 枚举值。
- `MiniNvm_Test.h`：移除已删除用例的 `MININVM_TEST_CASE_FAILURE` 宏。
- `MiniFlsIf.c`：补充实现说明注释（无功能改动）。

#### 5. 测试（`Codes/Test/MiniNvm_Test.c`，+50/−18）

- `BLANK`：空白读取期望由 `NOT_OK` 改为 `OK`，并校验读回全零。
- `ALL` / `ROTATE`：改用 `MiniNvm_WriteRam` 置脏后再 `WriteAll`。
- 删除 `CASE_FAILURE` 用例（默认值恢复路径已移除）。

#### 6. 文档

- `Docs/MiniFlsIf_SDD.md`：补充“MiniFlsIf 无自有配置”说明。
- `Docs/MiniStorage_集成手册.md`：同步块目录、一次性读写、`union` 缓冲、队列仅存元数据等说明；配置项改述为“性质/取值依据”。
- `README.md`、`Docs/变更记录.md`：新增/调整。
- 统一将作者更新为 **Manco**，版本提升至 **V1.1**（源码文件头 + 文档）。

### 兼容性说明

- **存储格式不兼容**：块头由 `1+2+4+1` 改为 `3+4+1` 字节，旧 Flash 数据无法直接沿用，升级需先擦除刷新。
- **API 变更**：新增 `MiniFee_ReadAll/WriteAll` 与 `MiniNvm_*Ram*`；移除 `MiniNvm_RestoreBlockDefaults` 与 `MININVM_REQ_RESTORED_FROM_ROM`。
- **配置结构变更**：`MiniNvm_BlockDescriptorType` 字段减少，`MININVM_QUEUE_SIZE` 语义变为用户自定义。

### 遗留 / 待办

## V1.0 — 2026/09/10

初版发布。

- 建立三层非易失存储栈：`MiniFlsIf`（平台适配）/ `MiniFee`（EEPROM 仿真）/ `MiniNvm`（逻辑块与请求队列），全部为异步状态机，按 `MiniFlsIf → MiniFee → MiniNvm` 顺序周期调度。
- `MiniFee`：逻辑 Block 追加式写入，块头 `BlockNumber(1)+Length(2)+PrevOffset(4)+CRC-8(1)`；迁移时从 `lastRecordStart` 沿 `PrevOffset` 反向扫描并以位图按块去重；双簇轮换，写簇头前回读源簇 Generation +1。
- `MiniNvm`：块描述符 + RAM buffer，环形请求队列（条目内嵌数据缓冲），单块/多块异步请求，支持 `RestoreBlockDefaults` 默认值恢复（ROM 或回调）。
- `MiniFlsIf`：转发 RH850 Fls MCAL 异步接口。
- 提供开发阶段自检 `MiniNvm_Test`。
